# 📘 Módulo: Sistemas de Ecuaciones (Versión Avanzada — Reducción + Decisión)

***

# 🎯 Objetivo

Que el estudiante:

* vea un sistema como **una ecuación escondida**
* elija método rápidamente
* no se pierda en pasos
* reduzca sin pensar

***

# 🧠 1. Principio central

👉 Un sistema se reduce a **una sola ecuación**

```
2 ecuaciones → 1 variable → resolver
```

***

# ⚙️ 2. Estrategia híbrida

## Regla de decisión:

| Caso                      | Qué hacer             |
| ------------------------- | --------------------- |
| ya hay variable despejada | sustitución           |
| coeficientes similares    | eliminación           |
| apariencia simple         | lo que sea más rápido |

***

👉 objetivo:

> decidir en <2 segundos

***

# ✅ 3. Ejemplos (decisión en acción)

***

### Caso 1 — Eliminación directa

```
x + y = 10
x - y = 2
```

→ sumar:

```
2x = 12 → x = 6
```

→ sustituir → y = 4

***

### Caso 2 — Sustitución

```
y = 2x
x + y = 10
```

→ reemplazar:

```
x + 2x = 10
```

→ 3x = 10

***

### Caso 3 — Forma rara (tu caso real)

```
3 - 2x = 11
y = x + 1
```

👉 paso 1:

```
resolver la ecuación rara → x
```

👉 paso 2:

```
sustituir en la otra
```

***

👉 clave:

> primero simplifico cada ecuación si es necesario

***

# ❗ 4. Regla crítica

👉 No resuelvas el sistema completo de una vez

👉 reduce primero a una ecuación SIEMPRE

***

# ⚠️ 5. errores comunes

❌ intentar hacer todo al mismo tiempo  
❌ errores de signos  
❌ no elegir método

✅ regla:

> “una variable → una ecuación”

***

# ⚡ 6. Mini-check

* ¿puedo eliminar una variable?
* ¿puedo sustituir rápido?
* ¿ya reduje a una ecuación?
