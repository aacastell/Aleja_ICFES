# 📘 Módulo: Funciones (Versión Avanzada — Evaluación + Traducción + Equivalencia)

***

# 🎯 Objetivo

Que el estudiante:

* evalúe funciones sin pensar
* entienda que “f(x)” = reemplazo
* conecte funciones con ecuaciones automáticamente
* no vea funciones como algo nuevo

***

# 🧠 1. Principio central

👉 Una función es SOLO una máquina:

```
entra x → sale valor
```

Ejemplo:

```
f(x) = 2x + 3
```

***

# ⚙️ 2. Estrategia híbrida

### Regla de decisión:

✅ Si te dan f(3) → reemplazar directo  
⚠️ Si te dan f(x)=10 → resolver como ecuación

***

# ✅ 3. Ejemplos (decisión en acción)

***

### Caso directo (evaluación)

```
f(x) = 2x + 3
f(4)
```

→ 2(4) + 3  
→ 11

***

### Caso con estructura (sin escribir todo)

```
f(x) = 3x + 2
f(5)
```

→ 15 + 2  
→ 17

***

### Caso inverso (ecuación disfrazada)

```
f(x) = 2x + 3
f(x) = 11
```

→ 2x + 3 = 11  
→ x = 4

***

### Caso con paréntesis

```
f(x) = 2(x + 3)
f(4)
```

→ 2(7) = 14

***

# 🔁 4. Equivalencia clave (esto desbloquea todo)

```
f(x) = 2x + 3
```

ES lo mismo que:

```
y = 2x + 3
```

***

👉 y esto:

```
f(x) = 10
```

ES esto:

```
2x + 3 = 10
```

👉 o sea: ecuación lineal

***

# ❗ 5. Regla crítica

👉 **Reemplaza TODO x siempre**

***

# ⚠️ 6. errores comunes

❌ reemplazo parcial  
❌ no usar paréntesis  
❌ no ver que es una ecuación

✅ regla:

> “todo x → valor”

***

# ⚡ 7. Mini-check

* ¿reemplacé todo x?
* ¿resolví o solo evalué?
* ¿esto es una ecuación?

***

## ⚡ Bloque E — Traducción

1. Un valor inicial de 3 y aumenta de 2 en 2  
   → f(x) = 2x + 3

***

2. Costo con base 1000 y 500 por unidad  
   → f(x) = 1000 + 500x

***

3. El doble de un número más 1  
   → f(x) = 2x + 1

***
