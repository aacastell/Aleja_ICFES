# 📘 Módulo: Factorización (Versión Avanzada — Reconocimiento + Decisión)

***

# 🎯 Objetivo

Que el estudiante:

* reconozca patrones sin pensar
* no pruebe a ciegas
* verifique automáticamente
* convierta factorización en un reflejo

***

# 🧠 1. Principio central

👉 Factorizar es **reconocer una estructura escondida**

No es probar. No es adivinar.

Es ver:

```
x² + 5x + 6 → (x + 2)(x + 3)
```

***

# ⚙️ 2. Estrategia híbrida

### Regla de decisión:

✅ Si ves el patrón → factoriza directo  
⚠️ Si no es obvio → prueba rápido y verifica

***

# 🔑 3. Los 3 patrones (TODO el juego)

***

## 🔹 Factor común

```
4x + 8 → 4(x + 2)
```

👉 buscar lo que se repite

***

## 🔹 Diferencia de cuadrados

```
x² - 9 → (x - 3)(x + 3)
```

👉 forma:

```
a² - b²
```

***

## 🔹 Trinomio

```
x² + 5x + 6
```

👉 buscar números que:

* sumen 5
* multipliquen 6

→ 2 y 3

***

# ✅ 4. Ejemplos (decisión en acción)

### Caso directo

```
x² + 5x + 6
→ (x + 2)(x + 3)
```

***

### Caso con patrón claro

```
x² - 16
→ (x - 4)(x + 4)
```

***

### Caso con factor común

```
6x + 12
→ 6(x + 2)
```

***

### Caso donde dudas

```
x² + 7x + 10
```

→ pruebas:

```
5 y 2
```

→ verificas:

```
5 + 2 = 7 ✅
5 × 2 = 10 ✅
```

***

# ❗ 5. Regla crítica

👉 SIEMPRE verificar expandiendo mentalmente

```
(x + 2)(x + 3)
→ x² + 5x + 6
```

***

# ⚠️ 6. errores comunes

❌ elegir números incorrectos  
❌ no verificar  
❌ forzar patrón incorrecto

✅ regla:

> “si no encaja exacto, no es ese patrón”

***

# ⚡ 7. Mini-check

* ¿reconozco el tipo?
* ¿los números cuadran?
* ¿puedo expandir de vuelta?

## ⚡ Bloque E — Traducción

1. El producto de dos números consecutivos es x² + x
