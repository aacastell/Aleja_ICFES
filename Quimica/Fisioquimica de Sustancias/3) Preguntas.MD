# ✅ RESPUESTAS Y EXPLICACIONES

1. **B** → Fusión = sólido a líquido
2. **C** → Densidad no cambia sustancia
3. **B** → Homogénea = uniforme
4. **C** → Solo sólidos tienen forma fija
5. **B** → Cambia estado, no composición

***

6. **B** → Flota si su densidad es menor
7. **B** → Líquidos no miscibles → decantación
8. **D** → Gas = partículas separadas
9. **B** → Más temperatura = más movimiento
10. **C** → Oxidación = cambio químico

***

11. **B** → ρ = m/V → aumenta V → baja ρ
12. **C** → Saturada = máximo soluto
13. **C** → Combustión no separa, transforma
14. **B** → Sólido → gas
15. **B** → Se forma nueva sustancia

***

16. **B** → Más fuerza = más energía para hervir
17. **C** → Igual densidad → equilibrio
18. **C** → Ley de conservación de masa
19. **B** → Sólido no disuelto → filtración
20. **B** → Más presión → menos volumen

***

21. **B** → Ebullición en toda la masa
22. **C** → Partículas juntas → estructura rígida
23. **C** → No se mezclan → heterogénea
24. **C** → Energía = movimiento
25. **B** → No cambia composición

***

26. **C** → La temperatura se mantiene → cambio de estado
27. **B** → Fuerzas débiles → evaporan fácil
28. **C** → m/V igual → densidad constante
29. **C** → No hay reacción → separable
30. **C** → Más fuerza → mayor punto de ebullición
