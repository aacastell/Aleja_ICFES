# 🧪 ESTEQUIOMETRÍA – TIPO ICFES

## ✅ 1. ¿Qué es la estequiometría?

Es el estudio de **las relaciones cuantitativas entre reactivos y productos** en una reacción química.

En el ICFES, te evalúan si puedes:

* Interpretar ecuaciones químicas
* Usar proporciones (regla de tres)
* Convertir entre:
  * gramos ↔ moles
  * moles ↔ moléculas
  * reactivos ↔ productos

***

## ✅ 2. PASOS CLAVE (muy importante para ICFES)

### 🔹 Paso 1: Balancear la ecuación

Ejemplo:

```
H₂ + O₂ → H₂O
```

Balanceada:

```
2H₂ + O₂ → 2H₂O
```

***

### 🔹 Paso 2: Convertir a moles

Fórmula:

```
moles = masa / masa molar
```

***

### 🔹 Paso 3: Usar la proporción

De la ecuación:

```
2 mol H₂ → 2 mol H₂O
```

***

### 🔹 Paso 4: Volver a gramos (si piden masa)

```
masa = moles × masa molar
```

***

## ✅ 3. EJEMPLO TIPO ICFES

### 📌 Pregunta:

¿Cuántos gramos de agua (H₂O) se producen al reaccionar 4 g de H₂?

***

### 🔹 Paso 1: Ecuación

```
2H₂ + O₂ → 2H₂O
```

***

### 🔹 Paso 2: Moles de H₂

Masa molar H₂ = 2 g/mol

```
moles H₂ = 4 / 2 = 2 mol
```

***

### 🔹 Paso 3: Relación molar

```
2 mol H₂ → 2 mol H₂O
```

Entonces:

```
2 mol H₂ → 2 mol H₂O
```

***

### 🔹 Paso 4: Gramos de H₂O

Masa molar H₂O = 18 g/mol

```
masa = 2 × 18 = 36 g
```

✅ **Respuesta: 36 g de H₂O**

***

## ✅ 4. TIPOS DE PREGUNTAS ICFES

### 🔥 1. Cálculo directo

* ¿Cuántos gramos se producen?

### 🔥 2. Reactivo limitante

* ¿Quién se acaba primero?

👉 Estrategia:

* Calculas cuánto producto forma cada reactivo
* El que produce menos = limitante

***

### 🔥 3. Rendimiento porcentual

Fórmula:

```
% rendimiento = (real / teórico) × 100
```

***

### 🔥 4. Interpretación (MUY común)

Ejemplo:

> Si se duplican los reactivos, ¿qué pasa con el producto?

✅ Respuesta:
→ También se duplica (proporcionalidad)

***

## ✅ 5. TRUCOS PARA EL ICFES

✔ Siempre usa **la ecuación balanceada**  
✔ Trabaja en **moles, no en gramos directamente**  
✔ Usa **regla de tres simple**  
✔ Revisa unidades (error común)  
✔ El ICFES mezcla matemáticas + química (razón y proporción)

***
