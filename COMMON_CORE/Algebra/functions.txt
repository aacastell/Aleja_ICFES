
📘 Funciones — Teoría + Entrenamiento Progresivo
Objetivo: que el estudiante convierta las funciones en un sistema de lectura e interpretación automática.
Principio central:
👉 una función es una máquina: entra x, sale un valor


🧠 1. ¿Qué es una función?
Una función toma un número (entrada) y produce otro (salida).
Forma general:
f(x) = expresión
Ejemplo:
f(x) = 2x + 3


⚙️ 2. Cómo usar una función
Para evaluar una función:
👉 reemplazar x por el valor dado


Ejemplo 1
f(x) = 2x + 3
f(2) = 2(2) + 3 = 7


Ejemplo 2
f(x) = 3x - 1
f(4) = 3(4) - 1 = 11


🔑 3. Interpretación
En funciones lineales:
f(x) = mx + b

m → cambio (pendiente)
b → valor inicial


Ejemplo
f(x) = 500x + 3000

3000 → valor inicial
500 → incremento por unidad


✅ 4. Ejemplos resueltos
Ejemplo 1
f(x) = x + 5
f(3) = 3 + 5 = 8


Ejemplo 2
f(x) = 2x + 1
f(5) = 10 + 1 = 11


Ejemplo 3
f(x) = 4x - 3
f(2) = 8 - 3 = 5


Ejemplo 4 (contexto)
Costo:
C(x) = 2000 + 300x
C(4) = 2000 + 1200 = 3200


Ejemplo 5 (invertido)
f(x) = 2x + 3
Si f(x) = 11:
2x + 3 = 11
Resolver como ecuación:
2x = 8 → x = 4


⚠️ 5. Errores comunes
❌ No reemplazar correctamente ❌ olvidar paréntesis ❌ errores de operación
✅ regla:
"reemplazar TODO x por el número"


⚡ 6. Mini-check

¿replacé todo x?
¿hice bien las operaciones?
¿el resultado tiene sentido?
