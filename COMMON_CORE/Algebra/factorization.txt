
📘 Factorización — Teoría + Entrenamiento Progresivo
Objetivo: convertir la factorización en reconocimiento automático de patrones.
Principio central:
👉 factorizar es ir de expansión → a estructura


🧠 1. ¿Qué es factorizar?
Es escribir una expresión como producto de otras más simples.
Ejemplo:
x² + 5x + 6 = (x + 2)(x + 3)


🔑 2. Tipos fundamentales
1. Factor común
Sacar lo que se repite.
Ejemplo:
4x + 8 = 4(x + 2)


2. Diferencia de cuadrados
Patrón:
a² - b² = (a - b)(a + b)
Ejemplo:
x² - 9 = (x - 3)(x + 3)


3. Trinomio cuadrático
Forma:
x² + bx + c
Buscar dos números que:

sumen b
multipliquen c


Ejemplo:
x² + 5x + 6
→ 2 y 3
Resultado:
(x + 2)(x + 3)


⚙️ 3. Proceso mental

Identificar patrón
Aplicar fórmula correspondiente
Verificar (expandiendo mentalmente)


✅ 4. Ejemplos resueltos
Ejemplo 1 (factor común)
6x + 12
= 6(x + 2)


Ejemplo 2 (diferencia de cuadrados)
x² - 16
= (x - 4)(x + 4)


Ejemplo 3 (trinomio)
x² + 7x + 10
→ 5 y 2
= (x + 5)(x + 2)


Ejemplo 4 (ecuación)
x² + 5x + 6 = 0
(x + 2)(x + 3) = 0
Propiedad clave:
Si un producto es cero, al menos uno es cero.
x + 2 = 0 → x = -2 x + 3 = 0 → x = -3


⚠️ 5. Errores comunes
❌ Elegir números incorrectos ❌ olvidar revisar la multiplicación ❌ no reconocer patrón correcto
✅ regla:
"si no encaja perfecto, no es ese patrón"


⚡ 6. Mini-check

¿los números suman bien?
¿multiplican correctamente?
¿puedo expandir y recuperar la original?
