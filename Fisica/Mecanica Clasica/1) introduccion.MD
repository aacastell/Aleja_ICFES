# 🧠 ICFES – Mecánica Clásica (Física)

La mecánica clásica estudia el movimiento de los cuerpos y las fuerzas que lo causan. En el ICFES, suele aparecer en forma de análisis de situaciones, gráficos y problemas conceptuales.

***

## 1. 🔄 Cinética vs. Cinemática

* **Cinemática**: Describe el movimiento **sin importar las causas**.
* **Dinámica**: Explica el movimiento **a partir de las fuerzas**.

***

## 2. 📏 Magnitudes básicas

* **Posición (x)**: lugar del objeto.
* **Desplazamiento (Δx)**: cambio de posición.
* **Velocidad (v)**: qué tan rápido cambia la posición.
* **Aceleración (a)**: qué tan rápido cambia la velocidad.

***

## 3. 🚗 Movimiento Rectilíneo Uniforme (MRU)

* Velocidad constante.
* Aceleración = 0.

📌 Fórmula:

```
x = x₀ + vt
```

***

## 4. 🚀 Movimiento Rectilíneo Uniformemente Acelerado (MRUA)

* Aceleración constante.

📌 Fórmulas clave:

```
v = v₀ + at
x = x₀ + v₀t + ½at²
v² = v₀² + 2aΔx
```

💡 Tip ICFES: Interpretar gráficos **posición-tiempo** y **velocidad-tiempo**.

***

## 5. ⚖️ Leyes de Newton

### 🥇 Primera ley (Inercia)

Un objeto permanece en reposo o en movimiento uniforme si no hay fuerzas netas.

### 🥈 Segunda ley

```
F = ma
```

* Fuerza neta = masa × aceleración.

### 🥉 Tercera ley

* A toda acción corresponde una reacción igual y opuesta.

💡 Muy preguntado: diagramas de fuerzas (peso, normal, fricción, tensión).

***

## 6. 🧲 Tipos de fuerzas

* **Peso**:
  ```
  P = mg
  ```
* **Normal**: perpendicular a la superficie.
* **Fricción**:
  ```
  Ff = μN
  ```
* **Tensión**: en cuerdas o cables.

***

## 7. ⚡ Trabajo, Energía y Potencia

### Trabajo

```
W = F·d·cos(θ)
```

### Energía

* Cinética:
  ```
  Ec = ½mv²
  ```
* Potencial gravitacional:
  ```
  Ep = mgh
  ```

### Conservación de energía

```
E inicial = E final
```

### Potencia

```
P = W/t
```

***

## 8. 🔄 Movimiento circular

* Velocidad angular y centrípeta.
* Aceleración centrípeta:

```
a = v²/r
```

***

## 9. 📊 Gráficos importantes

El ICFES evalúa mucho interpretación:

* **x vs t** → pendiente = velocidad
* **v vs t** → pendiente = aceleración
* **Área bajo v-t** = desplazamiento

***

## 10. 🎯 Estrategia para el ICFES

✅ Lee el contexto antes de usar fórmulas  
✅ Identifica el tipo de movimiento  
✅ Usa gráficos cuando puedas  
✅ Comprende conceptos (no memorizar sin entender)  
✅ Descarta opciones absurdas

***

## 📌 Ejemplo tipo ICFES

Un carro acelera desde reposo a 4 m/s² durante 5 s. ¿Velocidad final?

```
v = v₀ + at
v = 0 + (4)(5) = 20 m/s
```
